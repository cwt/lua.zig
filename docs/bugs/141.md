# BUG-141 — `loadProtos` Leaves Uninitialized Wild Pointers in Proto `sub_protos` Slice

- **Severity:** `CRITICAL`
- **Status:** ⏳ OPEN
- **Location:** `src/lundump.zig:200-210` (`loadProtos`)

## Defect Summary

In `src/lundump.zig`:
```zig
fn loadProtos(self: *LoadState, f: *lua.lua_Proto) anyerror!void {
    const n = try self.loadInt();
    if (n < 0) return error.BadFormat;
    const sub_protos = try self.allocator.alloc(*lua.lua_Proto, @intCast(n));
    f.p = sub_protos; // Assign immediately; GC owns this via allgc

    var loaded: usize = 0;
    while (loaded < @as(usize, @intCast(n))) : (loaded += 1) {
        const sub = try lua.createProto(self.allocator);
        sub.is_sub = true;
        try lua.registerGC(self.L, sub);
        sub_protos[loaded] = sub;
        try self.loadFunction(sub);
    }
}
```

Notice that `f.p` is assigned the raw slice `sub_protos` before any of its elements are initialized.
If loading fails mid-way (e.g. `BadFormat`, EOF, or OOM inside `loadFunction(sub)`), or if a garbage collection cycle triggers during recursive loading:
- `f.p` contains pointers from `sub_protos[loaded..n]` that are uninitialized wild memory.
- `traverseGrayObject` in `src/lua.zig:4694-4698` iterates over `for (p.p) |sub_p|` and unconditionally marks `markObject(g, sub_p.gc)`.
- De-referencing `sub_p.gc` on an uninitialized address causes an immediate wild pointer dereference, segfault, or undefined memory corruption.

By contrast, `loadConstants` (lines 154–160) and `loadUpvalues` (lines 219–224) initialize their slices immediately with safe values (`.nil` or zeros).

## Impact

Any corrupted bytecode file or transient OOM during chunk parsing causes the VM to crash or corrupt heap memory during error unwinding or GC traversal.

## Proposed Fix

Either:
1. Initialize `sub_protos` or hold it in a temporary local variable until all sub-prototypes are fully loaded and initialized, assigning `f.p = sub_protos` only upon completion.
2. If `f.p` must be assigned early for GC tracking, make the slice elements nullable (`?*lua.lua_Proto`), initialize them all to `null`, and update GC traversal to check `if (sub_p) |p|`.
