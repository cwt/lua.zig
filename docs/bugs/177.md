# BUG-177 — Missing `math.cosh` / `math.sinh` / `math.tanh` / `math.log10`

- **Severity:** `MED` — incorrect results / errors on ordinary programs
  that use these functions.
- **Status:** ✅ FIXED
- **Location:** `src/lib/mathlib.zig` (function registration table), `src/libm.zig`.

## Defect Summary

`lua/lmathlib.c:731-736` registers `atan2`, `cosh`, `sinh`, `tanh`, `pow`, and `log10`
under `LUA_COMPAT_MATHLIB`. `luazig`'s `mathlib.zig` had omitted
`cosh`, `sinh`, `tanh`, `log10`, and `atan2`.

## Resolution

1. Added `cosh`, `sinh`, and `tanh` to `Libm` struct, `resolve()`, and fallbacks in `src/libm.zig`.
2. Implemented `math_cosh`, `math_sinh`, `math_tanh`, and `math_log10` in `src/lib/mathlib.zig`.
3. Registered `cosh`, `sinh`, `tanh`, `log10`, and `atan2` (alias to `math_atan`) in `openmathlib` table in `src/lib/mathlib.zig`.
4. Verified with unit test in `tests/test_basic.zig`. 191/191 unit tests pass; upstream 20/20 pass.
