# BUG-138 — Misc library/API divergences (differential-testing cluster)

- **Severity:** [LOW]
- **Status:** ✅ FIXED

- **Location / items:**
  - `src/lib/iolib.zig:250-253` (`io_popen`): read-mode pipes now inherit the parent's stdin instead of `.ignore`.
  - `src/lib/iolib.zig:295-320` (`io_tmpfile`): added 100-attempt retry loop on collision/EEXIST.
  - `src/lua.zig:3768-3773` (`lua_pcall` / `luaL_dostring`): maps error types faithfully (`LUA_ERRMEM`, `LUA_ERRERR`, `LUA_ERRRUN`, `LUA_YIELD`).

- **Impact:** Aligns behavior with POSIX / Lua 5.5.1 C reference.

Added unit tests in `tests/test_basic.zig`.
