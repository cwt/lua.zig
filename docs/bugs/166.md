# BUG-166 — `run_testes.sh` Skips 15 of 34 Upstream Files, Masking Real Failures

- **Severity:** `LOW` (tooling/process defect; it hides the `HIGH`/`CRITICAL`
  bugs above, so treat the *hidden* set as the real severity)
- **Status:** ❌ OPEN
- **Location:** `run_testes.sh:96-140` (`HEAVY_TESTS`, `T_TESTS`,
  `STANDALONE_SKIP`, `SKIP (harness)` rules)

## Defect Summary

The AGENTS.md claim "**PASS 19, FAIL 0** across the entire `lua/testes/*.lua`
suite" is only true *under the harness's skip rules*. The harness skips 15 of
34 files:

- **`SKIP (needs T)`** — 7 files requiring the reference `T` auxiliary module
  (`api.lua`, `code.lua`, `coroutine.lua`, `gc.lua`, `strings.lua`,
  `memerr.lua`, `tracegc.lua`).
- **`SKIP (needs all.lua)`** — `attrib.lua`, `big.lua`, `files.lua`,
  `literals.lua`, `heavy.lua`, `cstack.lua`.
- **`SKIP (harness)`** — `all.lua`, `main.lua`.

Re-measured standalone on 2026-09-08 (naive per-file run, cwd =
`lua/testes/`): **23 PASS / 11 FAIL**, with failures concentrated in the
skipped set, several being genuine interpreter bugs:

| File | Standalone result | Bug |
|---|---|---|
| `strings.lua` | FAIL :44 | [BUG-155](155.md) |
| `coroutine.lua` | FAIL :69 | [BUG-156](156.md) |
| `attrib.lua` | FAIL :138 | [BUG-157](157.md) |
| `gc.lua` | FAIL :15 | [BUG-158](158.md) |
| `files.lua` | FAIL :88 | [BUG-159](159.md) |
| `big.lua` | FAIL :56 | [BUG-160](160.md) |
| `cstack.lua` | **CRASH (core dump)** | [BUG-161](161.md) |
| `main.lua` | FAIL :193 | [BUG-165](165.md) |
| `all.lua` | FAIL (runs main.lua) | via [BUG-165](165.md) |

(The T-module files fail for missing-`T` environmental reasons; not logged as
defects.)

## Impact

The documentation overstates conformance. Each skipped file that fails
standalone is unverified by CI until either the harness handles it (e.g.
provide a stub `T` module, or run files with their documented invocation) or
the underlying bugs are fixed.

## Proposed Fix

1. Update AGENTS.md / docs to state the skip list explicitly alongside the
   PASS/FAIL numbers (no bare "PASS 19, FAIL 0" claim).
2. Provide a minimal Zig-implemented `T` auxiliary module (the reference
   `lua/testes/libs/T` C library) so the 7 T-tests can run.
3. Grow the harness to run the `STANDALONE_SKIP` set in the correct
   environment (they mostly need `all.lua`'s prelude `_port`/`_soft` globals
   and `libs/` fixtures) or run them standalone after fixing the bugs above.
4. Track standalone results per file as the true conformance metric.
