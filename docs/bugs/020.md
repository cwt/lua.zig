# BUG-020 — `luaL_newmetatable` key mismatch + `lua_setmetatable` index shift

- **Severity:** [MED]
- **Status:** ✅ FIXED

- **Location:** `src/lauxlib.zig:432-445` (`luaL_newmetatable`), `:480-492` (`luaL_testudata`); `src/lua.zig:2450-2465` (`lua_setmetatable`).
- **Defect:** `luaL_newmetatable` used pointer keys (`lua_rawgetp`/`lua_rawsetp`) instead of string keys (`lua_getfield`/`lua_setfield`), causing mismatch with lookup in `luaL_setmetatable`/`luaL_testudata`. `lua_setmetatable` resolved target index after popping the metatable, causing negative relative stack indices to shift.
- **Impact:** Metatable registration and type assertions in auxlib failed to find registered tables by name in the registry; negative indices passed to `lua_setmetatable` operated on the wrong stack slot.
- **Fix:** Switched `luaL_newmetatable` to `lua_getfield`/`lua_setfield`. Resolved target index via `lua_absindex` in `lua_setmetatable` before popping. Exported `luaL_newmetatable`/`luaL_setmetatable`/`luaL_testudata`/`luaL_checkudata` from `lauxlib.zig`. Added unit test in `tests/test_basic.zig`.
